# 功能与已知边界（0.9.0 Alpha）

| 能力 | 已实现 | 边界 |
| --- | --- | --- |
| 独立聊天与设置 | F9 半透明可拖动/缩放界面；六页设置与历史 | 实机图形与所有分辨率尚需进一步验收 |
| 村民交谈 | 邻近、符合条件的 2–4 人轮流对话，冷却与调用预算 | 不会自动全地图寻找聊天对象；没有因此执行世界动作 |
| 追溯 | 实际上下文、提示词、回复、耗时、用量与行动结果；有界记录 | 服务未报告用量即未知；不能推算真实账单；记录含玩家隐私 |
| 原版台词续聊 | 普通安全日常台词自动改写；SocialValley 桥接 | 剧情选项、多页和回调等复杂对话不接管；不是改写所有原版文本 |
| 当前活动 | 从真实路线、日程动作、动画和已验证执行器派生有限状态 | 未知动作保留未知；时钟和口头描述不能证明正在工作 |
| 日程与喜好 | 当前游戏选择的日程及少量后续节点；本人实际礼物反应 | 不是全世界完整剧透；另一 NPC 的私人计划不直接共享 |
| 潘妮上课 | 精确教室格/读书动作及附近学生条件同时满足后细化活动 | 属于有条件的活动注释，不模拟课程进度；不硬编码钟点 |
| 剧情记忆 | 封存剧情按发生事实解锁；实际显示台词按见证者记录；潘妮分支识别 | 不覆盖全部原版/SVE 事件；旧存档缺少的分支证据不猜测 |
| 陪同/出行/约会 | NPC 同意、地点解析、真实寻路、到达/等待/取消/失败与返回 | 不开放任意教学、制作、改写全日程；未来约会不会立即替换当前活动 |
| 移动合法性 | 路线、下一格、跨地图连接验证；检测控制权被其他模组替换 | 动态阻塞可能导致受阻/中断，不能保证所有地图都存在可达路线 |
| 环境感知 | 有界实体、稳定标识、视线/隐私过滤及第三方描述接口 | 未实现每个未知模组的语义，不自动理解所有自定义宠物/机器 |
| SVE | 依据 1.15.11 内置 41 个角色 ID 人格，按内容包自动启用 | ID 数不等于独立人物数；新版本、新事件和地图仍需验证 |
| 其他人物 | 原版少量专用人格与通用回退 | 当前原版专用人格仅 Abigail、Harvey、Sebastian、Pierre、Wizard；无 RSV/East Scarp 专用包 |
| 语言 | 六种界面语言随游戏变化，活动和控制提示同步 | 自然语言解析及模型输出不保证完全等价；繁中需字体/语言包 |
| 世界可信性 | 结构/权限/前提校验，游戏主线程读写，模型异步，丢弃过期回复 | 无验证执行器的叙述只是台词；不保证模型永不产生事实错误 |

目前没有完整 RimWorld 式工作/需求系统、任意自主漫游或全模组通用智能。主要开发验证平台为 Windows，非 Windows 和完整多人游戏支持没有完成验收。当前发布属于 Alpha。

机制详见 [活动状态](job-state.md)、[开发指南](development.md) 与 [安装说明](installation.md)。
