# StardewAIWorld

让星露谷村民结合真实日程、周围环境和已经发生的经历聊天，并在验证与同意后执行陪同、出行和约会。游戏状态由代码维护，模型负责表达和有限动作提议。

**当前版本：0.9.0 Alpha（2026-10-15）**。适合愿意反馈问题的玩家；离线验证不等于完整实机验收。

## 前置

| 项目 | 是否必需 | 说明 |
| --- | --- | --- |
| Stardew Valley 1.6 桌面版 | 是 | 不包含游戏文件；当前开发验证在 Windows 上进行 |
| [SMAPI](https://smapi.io/) 4.0+ | 是 | 通过 SMAPI 启动游戏 |
| 可用的模型服务与自己的 API Key | AI 对话需要 | 支持 DeepSeek 路由及兼容 Chat Completions 的服务；模型 ID 按账户实际可用值填写 |
| [SocialValley](https://github.com/CarlosNahuelcoy/SocialValley) | 原版/聊天 UI 桥接需要 | 对接参考版本 1.10.1；AIWorld 自带 F9 聊天面板可独立使用 |
| Stardew Valley Expanded（SVE） | 可选 | 内置 1.15.11 对应的 41 个角色 ID 人格条目，加载内容包后启用；SVE 自身前置仍需另装 |
| The Stardew Squad | 可选 | 当前玩家陪同使用原生执行器，无需为了 AIWorld 安装它 |
| Wizardry / ManaBarAPI | 可选 | 魔法相关观察集成；未安装不影响基础聊天 |

不捆绑以上第三方模组。AIWorld 不要求 Player2。里奇塞德村和东斯卡普尚无专用人格包。

## 已实现

- F9 半透明、可拖动和调整大小的聊天面板，包含聊天、历史、基础、提示词、上下文和模型设置页。
- 邻近可参与村民的 2–4 人轮流交谈；保留实际提示词、回复、耗时、token 用量和行动结果，便于追溯。
- 原版普通日常台词自动改写和续聊，支持与 SocialValley 切换；剧情、选项及带回调等复杂对话保留原流程。
- 读取当前加载的真实日程、本人礼物喜好、环境对象及当前活动。模型能区分正在赶路、读书、跟随、等待、返回和受阻。
- 封存剧情按已验证的发生事实解锁；现场台词按在场见证者记录。潘妮澡堂邀请包含分支识别，未知选择不补写记忆。
- NPC 同意后陪同、独立前往、预约会面；地点、路径、下一格和跨地图连接由代码验证，取消或失败后尝试恢复原安排。
- 游戏语言跟随：简中、繁中、英语、日语、韩语、西语。繁中需要相应游戏语言/字体支持。
- 模型输出经过结构、语义和权限验证；过期回复丢弃，模型叙述不能直接修改真实世界。

## 开始使用

1. 下载上方安装包，将其中 `AIWorld.Demo` 文件夹放进游戏 `Mods`。
2. 用 SMAPI 启动并进入存档，按 **F9** 打开模型设置，填写自己的服务地址、模型 ID 和 Key。
3. 选择 NPC 对话，例如询问“你现在在做什么？”、“陪我去沙滩”或“明天 21:00 在沙滩见”。安装 SocialValley 后可使用 **F8** 的安全对话切换。

连接测试和聊天会向你配置的服务发送上下文，可能产生费用。默认自动村民交谈有每日预算，但该预算不包含手动聊天、日常台词改写、连接测试和重试。Windows 上界面保存的 Key 写入用户环境变量；其他系统仅在当前进程有效。安装包不包含 Key，报告也会脱敏凭据，但聊天报告仍可能包含私人对话。

## 当前边界

这是 Alpha：没有完整 RimWorld 工作/需求系统或自主全地图闲逛；对话改动的是已开放的临时行动，不是任意改写整张日程表。原版专用人格和剧情覆盖尚不完整，不能宣称所有模组或事件已经适配。多人游戏及非 Windows 平台尚未完整实测。具体限制见功能表。

源码使用 .NET 8 SDK 构建，游戏模组目标为 net6.0。开发、验证与扩展入口见开发指南。仓库暂未附加独立开源许可证，第三方内容权利归原作者所有。
