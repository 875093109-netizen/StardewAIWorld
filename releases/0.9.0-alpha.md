# 0.9.0 Alpha · 2026-10-15

首次公开整理源码、安装包与开发说明。安装前请阅读 [前置与配置](../docs/installation.md)，完整范围见 [功能表](../docs/features.md)。

本版重点是可验证的当前活动：NPC 从真实日程、动画、路径、陪同/出行/约会执行器知道自己正在做什么；F9 可查看当前活动，玩家聊天、原版日常改写和村民聊天共享这一事实。活动变化会使在途旧回复失效。潘妮课堂描述需要实际位置、动作及附近学生同时满足。

同时公开已有的 F9 六页设置与追溯、邻近多人聊天、日常台词续聊、六语言、SVE 可选人格、日程/喜好/环境上下文、剧情见证记忆和带合法性检查的行动链。

发布验证：独立源码快照 Release 构建和六组离线测试；测试不调用付费模型。结果见 `verification.md`。本版本尚未完成全模组组合、多人、其他平台及完整实机流程验收，因此标记 Alpha。

安装包只含 AIWorld 自有运行文件，玩家需自备游戏、SMAPI、模型服务；SocialValley 仅在使用其 UI 桥接时需要。仓库内提供 ZIP 下载，此文件不是对 GitHub Releases 页面已建立发布条目的声明。
